# さんちゃん Go 2　バグ大王の逆襲（HTML_CSS_3chanGO2）

「さんちゃん Go」の続編です。HTML・CSS・JavaScript を書きかえて、バグ大王に書きかえられた世界を攻略するステージ攻略ゲームです。

- 中学校 技術・家庭科（技術分野）「情報の技術」向けの教材です。
- 全6ステージ。後半ほど意地悪なしかけが増え、最後はバグ大王とのボス戦です。
  - ST1 ちぢめ！さんちゃん（CSS：主人公の大きさ）
  - ST2 動く足場（CSS：`animation` と `@keyframes`）
  - ST3 月面ステージ（JavaScript：重力 `gravity`）
  - ST4 スイッチの部屋（HTML：`id` とブロック、JavaScript：`link`）
  - ST5 罠だらけの道（3つ全部：コードを読んで罠を見やぶる）
  - ST6 バグ大王（かくれたスイッチ、4つ同時押し、地上戦、第二形態との空中戦）
- スタート画面で「スタート」をおすと予告編（`sanchan2_pv.mp4`）が流れます。スキップできます。
- バグ大王（第2形態）をたおすと、エンディング動画（`sanchan2_ed.mp4`）が流れます。スキップできます。
- 罠はすべてコードに書いてあります。コードを読めば、必ず見やぶれます。

## 遊び方

`index.html` をブラウザで開くと動きます。予告編の動画 `sanchan2_pv.mp4` とエンディング動画 `sanchan2_ed.mp4` は、`index.html` と同じ場所に置いてください。GitHub Pages で公開する場合は、リポジトリの Settings → Pages で `main` ブランチを選んでください。

- 左がゲーム画面、右がHTML／CSS／JavaScriptのエディタです。コードを書きかえて「反映して遊ぶ」をおします。
- 操作：← → で移動、スペースでジャンプ、R でやり直し。
- ボス戦にはチェックポイントがあります。「ボス戦を最初から」で最初にもどせます。
- コードと記録は、その端末のブラウザに自動で保存されます。
